# Сайт Тетяни Завʼялової — психолога

**Live:** [tetiana-zavialova.com](https://tetiana-zavialova.com)

Одно-сторінковий сайт для практикуючого психолога. Розроблено в рамках портфоліо [Painted Fox Studio](https://paintedfox.studio).

---

## Стек

Vanilla HTML / CSS / JS — без фреймворків і залежностей.

## Особливості

- Адаптивний дизайн (мобільний / десктоп)
- Карусель відгуків і галерея фото — власна реалізація на чистому JS (infinite loop, clone-based)
- Попап запису з різними повідомленнями залежно від типу (консультація / супервізія / співпраця)
- Плавні анімації появи секцій (IntersectionObserver)
- Lightbox для галереї
- Веселковий градієнт на тексті про гендерну ідентичність 🏳️‍🌈
- Підключено Google Search Console + sitemap.xml
